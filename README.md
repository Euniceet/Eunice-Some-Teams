# Some Teams

A PHP website displaying information about women's football teams.

## Features

- Displays team names and club logos.
- Shows each team's city and league.
- Displays UEFA coefficient rankings and league positions.
- Provides links to the official team websites.
- Includes a shared header and an About page.

## Technologies

- PHP
- HTML
- Git and GitHub
- Css
